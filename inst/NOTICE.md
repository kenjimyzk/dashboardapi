`dashboardapi` is an unofficial, independently developed R client for the
Statistics Dashboard Web API provided by the Statistics Bureau of Japan.

It is not affiliated with, endorsed by, or maintained by the Statistics
Bureau of Japan. Users remain responsible for checking and complying with the
current official API documentation and site policy:

- https://dashboard.e-stat.go.jp/en/static/api
- https://dashboard.e-stat.go.jp/en/static/sitePolicy
